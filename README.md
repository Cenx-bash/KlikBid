📱 KlikBid

KlikBid is a modern Filipino auction app designed to make buying, selling, and bidding as quick and exciting as a single tap. Inspired by the sound of a “klik,” the app embodies speed, simplicity, and digital ease, while “bid” highlights its core purpose—bringing people together to compete and win offers in real time.

✨ Features
🔹 Real-time auction system
🔹 “Buy Now” instant purchase option
🔹 Auto-bid with maximum spending limit
🔹 Local payment integration (GCash, Maya, bank cards)
🔹 Escrow-secured transactions
🔹 Push notifications for bids and wins
🔹 Courier delivery integration
🔹 Ratings & reviews for trust and reliability
🔹 Lightweight, mobile-friendly design
🎯 Purpose

KlikBid provides Filipinos with a safe, fun, and exciting marketplace where anyone can buy or sell through auctions—combining local payment methods, secure transactions, and a simple mobile-first interface.

🛠 Tech Stack
Language: Java
Framework/IDE: Android Studio
UI/UX Design: Figma
Database: Firebase (optional for real-time sync)
Platform: Android 12+ (iOS support in the future)
